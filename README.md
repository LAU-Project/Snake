# Snake
This is a small game developped in Python thanks to Pygame lib by the LAU Project team.

## Dependencies 

- Pygame
- Pygame menu
- Requests

## How to initialize the game ?
You simply have to give the permission to the init.sh file with the following command:
```bash
chmod 755 init.sh
./init.sh
```

# How to run the game ?
Whenever you want to launch the game run the following command:
```bash
./run.sh
```
